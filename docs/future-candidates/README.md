# Focus on Dot Future Candidates

この文書は、MVP範囲外の将来的な機能候補を蓄積する場所である。ここに書かれた項目は実装要件でも
受け入れ条件でもない。実装を検討する段階になったら、比較・判断をしたうえで
[`../product.md`](../product.md)の検証候補・将来候補、または独立した機能仕様（`docs/<feature>.md`）へ
反映してから実装する。

## 候補一覧

| 候補 | 概要 |
| --- | --- |
| [人物タグ](./person-tags.md) | Dotを家族などの人物単位でも振り返れるようにする。 |
| [写真・動画の関連付け](./photo-video.md) | 音声だけでなく、写真・動画もDotに関連付ける。 |
| [年間ダイジェスト生成](./annual-digest.md) | 音声・写真・動画・出来事から一年の振り返り動画を自動生成する。 |

## 候補を追加する

新しいアイデアを思いついたら、このディレクトリへ1候補1ファイルで追加し、上の候補一覧に行を足す。
最初は概要だけの数行でよい。検討が進んだら、そのファイルへ背景・比較・関連リンクを書き足していく。

## この文書の位置づけ

- `product.md`はMVPの目的・範囲・受け入れ条件の正本である。この文書の項目をそのままMVP要件として
  扱わない。
- `product-vision.md`はFoDを作る理由と長期的な方向性を扱う。この文書は、その方向性の下で今後増えて
  いく具体的な機能候補を記録する場所であり、項目を思いついた時点で追加してよい。
- 項目の実装を検討する段階になったら、`product.md`の検証候補・将来候補、または独立した機能仕様へ
  判断とともに反映してから実装する。
