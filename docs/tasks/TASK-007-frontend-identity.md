## 目的と作業範囲

採用した方式でWebから認証を利用し、本人の録音・生成・履歴へ進めるようにする。画面や外部認証への遷移はTASK-001で決めた範囲に従う。個人データの端末保持・消去はTASK-014が担当し、本タスクは認証状態の通知・画面制御を担当する。

## 確認可能な完了条件

- [ ] 認証の開始・終了と失効をWebで扱い、利用者に現在の認証状態と次の操作が分かる。
- [ ] 未認証時の保護対象へのアクセス、API呼び出し中の認証失効を、正式なerror契約に従って扱う。
- [ ] 採用方式に従って資格情報を受け渡し、localStorageのDotや利用者IDを認証根拠にしていない。
- [ ] 認証の終了・切り替わりを個人データのstate管理へ伝達し、TASK-014と接続する境界がある。
- [ ] 実装に対応する関連現行文書を更新している。
