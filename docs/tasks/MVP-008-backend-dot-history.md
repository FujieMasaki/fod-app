## 目的と作業範囲

serverをDotの正本とし、利用者ごとに複数Dotを永続保存してDay・一覧・詳細から取得できるようにする。更新の扱いはMVP-002 / MVP-005で確定した範囲に限る。AI生成はMVP-009、保持期限と削除連鎖はMVP-013で扱う。

## 確認可能な完了条件

- [ ] Dotを認証済み利用者に関連付けて永続保存でき、新しいDotの保存で過去のDotが仕様に反して失われない。
- [ ] 同日の複数録音、日付境界、表示順を決定済みルールどおりに扱い、Dayに必要なデータを取得できる。
- [ ] 本人の一覧と指定した過去のDot詳細を取得でき、件数が増えても任意の過去のDotまで取得を続けられる。
- [ ] 未認証や別利用者からの一覧・詳細・更新を拒否し、決定した更新操作がある場合は本人だけが実行できる。
- [ ] 必要な項目だけを契約どおり返し、保存失敗と未取得の結果を区別できる。
- [ ] 関連する現行仕様・architectureへ実装済み範囲を反映している。
