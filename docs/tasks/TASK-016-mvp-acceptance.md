## 目的と作業範囲

モックではない接続で、録音→生成→永続保存→今日のDay→丸いDot一覧→過去の詳細という完成条件を確認する。個別タスクの検証証跡を利用し、機能をまたぐ失敗・中断・再試行と理解可能な表示を重点確認する。

## 確認可能な完了条件

- [ ] 認証済み利用者が実際の録音内容からDotを得て保存し、再読込後も本人の保存済みDotを表示できる。
- [ ] Dayで今日のDotを大きく見て一覧へ進み、丸い複数Dotから任意の過去の詳細へ到達できる。件数が増えた場合も確認済みである。
- [ ] 権限拒否、録音中断、送信/生成/保存の失敗、再試行で、実際の保持状態と結果・次の操作が利用者に分かる。
- [ ] 同日複数録音・記録のない日・日付境界・履歴の取得失敗・選択したDot未取得の結果が確定した仕様に一致する。
- [ ] mockと実サービスを混同せず、API request / response / errorの契約整合・schema検証と互換性の確認結果が揃っている。
- [ ] TASK-015の検証を含め、3仕様の完成条件ごとの証跡・実施環境をPlanへ記録している。未検証の完成条件が残る場合はDoneにしない。
- [ ] 実サービス化した現状を3仕様とarchitectureで確認し、実装済み・未決定・対象外の記述に不整合がない。
