## 目的と作業範囲

今日のDotと過去の任意のDotを選べるMVP体験に必要な保存・日付・表示のルールを決める。「Dot = その日の自分」はモチーフとして扱い、同日の保存件数・統合方法を推測で固定しない。

## 確認可能な完了条件

- [ ] 同日の複数録音の保存・表示上の扱い、Dayで今日のどのDotを表示するかが決まっている。
- [ ] 日付境界のタイムゾーン、履歴の並び順、記録のない日とDotが一件もない場合の表現が決まっている。
- [ ] Dayから一覧、一覧から詳細への導線と丸いDotの配置・選択方法を決め、日付と対象を色・サイズだけに頼らず判別できる。
- [ ] 保存件数が増えても過去の任意のDotへ到達できる取得・表示方法を決め、MVP-005で定義する境界が整理されている。
- [ ] 色・サイズの意味付けや線の要否のうちMVP一覧に直接必要な部分だけを決め、感情の決めつけや過去の評価を避ける。
- [ ] product / journaling / dot-historyの該当未決定事項を更新し、Week / Monthや検索等をMVP条件に加えていない。
