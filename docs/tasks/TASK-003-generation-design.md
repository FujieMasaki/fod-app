## 目的と作業範囲

録音内容から個々のDotを生成するprovider、prompt、文字起こしの有無、同期/非同期、失敗・中断・再試行と冪等性を決める。AI処理をBackendに置く方針を前提とする。TASK-002と相互に整合を確認するが、選択肢整理は並行して着手できる。

## 確認可能な完了条件

- [ ] provider、promptと生成結果の必要項目、文字起こしの採否・用途が決まり、録音内容からDotを生成する方法を説明できる。
- [ ] 応答時間と失敗時UXを踏まえて同期/非同期を決め、非同期を採用する場合だけJob基盤と結果取得方法を確定している。
- [ ] 送信・生成・保存の各状態と失敗時の再開点、音声を再利用できない場合の利用者への案内が定義されている。
- [ ] 再送・retry・Job再実行時に二重のDotや外部AI処理を防ぐ方法、または防げない範囲と利用者へ結果を明示する方法を決めている。
- [ ] TASK-002の保持・削除条件と整合し、product / journalingとarchitectureへ決定を反映している。
