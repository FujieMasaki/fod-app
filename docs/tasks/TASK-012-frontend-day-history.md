## 目的と作業範囲

現在の1件だけを表示する仕組みを、本人のserver保存済みDotのDay・一覧・選択した詳細へ拡張する。既存のDot / reflection表示を活用し、今日のDotと過去に選択したDotを取り違えないようにする。Week / Month、検索・カテゴリ・期間フィルタは含めない。

## 確認可能な完了条件

- [ ] Dayで今日のDotを大きく表示し、今日の記録がない場合も決定したルールに従って示す。過去のDotを今日の記録として扱わない。
- [ ] Dayから一覧へ進め、複数のDotを丸として見渡せる。日付と選択対象を色・サイズだけに頼らず判別でき、感情を決めつける表現にしない。
- [ ] 一覧で任意の過去のDotを選び、そのDotの内容を振り返れる。件数が増えても取得・表示の続きをたどって到達できる。
- [ ] 同日の複数録音、日付境界、並び順、記録のない日の表現がTASK-004と一致する。
- [ ] 履歴なし・読み込み中・一覧の読み込み失敗・選択したDotを取得できない場合を区別し、別のDotを代わりに表示しない。
- [ ] 本人のAPIデータを正本として表示し、dot-history / journaling等へ実装済みの範囲を反映している。
